# GitHubアカウント作成手順

1. GitHub 公式サイト（[https://github.com/](https://github.com/)）右上の「Sign up」をクリックします。もしくは中央の「メールアドレスを入力」欄にメールアドレスを入力して「GitHubに登録」をクリックします。
2. 「Sign up to GitHub」画面で必要な情報を入力して「Create Account」をクリックします。
3. 登録に使用したメールアドレスに届いた認証コードを画面に入力します。
4. 認証が成功するとログイン画面に遷移します。上の手順で入力したメールアドレスとパスワードを使用してログインできれば、アカウントの作成は完了です。

## GitHub Copilot利用準備

1. GitHub にログインします。
2. ホーム画面左上のメニューボタンをクリックします。
3. 「Copilot」をクリックします。
4. GitHub 上のGitHub Copilot Chat が開き、Copilot Free が使用できるようになります。
