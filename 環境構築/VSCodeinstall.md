# VS Code のインストール方法

この資料では、Windows で Visual Studio Code（VS Code）をインストールする手順を説明します。

## 1. VS Code のダウンロード

1. Microsoft の公式サイトにアクセスします。
   - https://code.visualstudio.com/
2. 画面上部の「Download for Windows」をクリックします。
3. インストーラーのダウンロードが始まります。
   - 通常は `VSCodeUserSetup-x64-<version>.exe` の形式でダウンロードされます。

## 2. インストーラーを実行する

1. ダウンロードしたファイルをダブルクリックして起動します。
2. 「次へ」をクリックして進めます。
3. 使用許諾契約に同意し、「次へ」を選択します。
4. インストール先のフォルダを確認し、「次へ」をクリックします。

## 3. オプションを選んでインストール

インストール時に次の項目を確認します。

- デスクトップ上にアイコンを作成する
- スタートメニューに追加する
- エクスプローラーのコンテキストメニューに追加する
- PATH に追加する

必要に応じてチェックを入れて、「次へ」をクリックします。

> 「PATH に追加する」を選ぶと、コマンドラインから `code` コマンドで VS Code を開けるようになります。

## 4. インストール完了

1. 「完了」をクリックしてインストールを終了します。
2. 「Launch Visual Studio Code」にチェックが入っている場合は、そのまま VS Code が起動します。
3. 起動しない場合は、デスクトップのアイコンやスタートメニューから VS Code を起動してください。

## 5. VS Code が起動したか確認する

起動後、画面左上のメニューバーから以下を確認します。

- ファイル
- 編集
- 表示
- ターミナル

これらが表示されていれば正常にインストールされています。

拡張機能は、VS Code 左側の拡張機能アイコン（四角形の中に四角形）から検索してインストールできます。

## 6. 動作確認

VS Code を開き、メニューの「ファイル」→「新しいファイル」でテキストファイルを作成し、適当に文字を入力してみてください。

問題なく編集できればインストールは完了です。
