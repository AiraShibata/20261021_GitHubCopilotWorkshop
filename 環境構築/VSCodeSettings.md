# VS Code初期設定
## 日本語に変更

- 左下の歯車アイコンから`Extensions`→`Japanese Language Pack`で検索
- 「Japanese Language Pack for Visual Studio Code」拡張機能を選んで`install`をクリック
- 右下の`Change Language and Restart`をクリックしてVSCodeを再起動
- 再起動後、VSCodeが日本語表示になっていることを確認
※「Change Language and Restart」を消してしまった場合
- Shift + Ctrl + Pを押す
- 上の検索欄で「Display」を検索
- `Configure: Display Language`をクリック
- `日本語」をクリック
- `Restart`をクリック


## GitHub Copilot利用準備

1. VSCodeを起動します。
2. 「Continue with GitHub」ボタンをクリックします。  
    ※もしくは右下のCopilotアイコンをクリックし、`AI features」ボタンをクリックします。
3. 「continue with github」ボタンをクリックします。
4. ブラウザでGitHubの認証画面が開きます。  
   （「Authorize Visual Studio Code」と表示されています。）
5. サインインに利用するアカウントがGitHub Copilotを使用開始済みであることを確認し、「Continue」ボタンをクリックします。
6. ブラウザ上で「このサイトはVisual Studio Codeを開こうとしています」とポップアップが表示されます。「開く」ボタンをクリックします。
7. GitHub Copilot の認証が完了です。
8. 「拡張機能」-「GitHub Copilot Chat」-「設定」から言語設定（Locale Override）を日本語（ja）に設定することで、GitHub Copilotが日本語で応答しやすくなります。
